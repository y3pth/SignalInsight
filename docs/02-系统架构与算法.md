## 3. 浏览器数值管线

### 3.1 数据校验

- 样本数 64–500,000；
- 时间严格递增；
- 实数、有限值；
- 采样间隔最大相对抖动不超过 5%；
- 首版只接受单通道。

### 3.2 频谱

- 去均值；
- Hann 窗；
- radix-2 FFT；
- 正频率幅度谱；
- 中位数幅度作为谱峰显著度基线。

### 3.3 模型

```text
y(t) = c + Σ Aᵢ sin(2πfᵢ(t-t₀)+φᵢ)
```

- 单频：1 个分量，4 个自由参数；
- 多频：2–3 个分量贡献候选；
- 给定频率时，通过线性最小二乘求 offset、cos/sin 系数；
- 频率通过 golden-section 搜索精化；
- 多频采用多轮坐标优化，最多 3 个频点。

### 3.4 模型竞争

- 同一数据、同一指标；
- BIC 为主要比较依据；
- 多频模型相对单频需要至少 10 的 BIC 优势和 10% RSS 降幅；
- 不满足时采用更简洁的单频模型。

### 3.5 可信度

证据包括：

- 主谱峰显著度；
- R² 与 RMSE；
- 残差最大绝对 ACF；
- 残余谱主峰显著度；
- 观测时长与频率分辨率。

结论等级：

- `reliable`；
- `caution`；
- `unreliable`；
- `insufficient_evidence`。

纯噪声或 R² < 0.5 时输出 unknown，不强行推荐模型。

## 4. AI 解释层

- LLM 不参与 FFT、参数估计、指标或可信等级计算。
- 只发送结构化数值摘要，不发送原始序列。
- 输入限制 64 KiB。
- 上游超时 25 秒。
- 输出经验证后取 `summary / observations / limitations`。
- 密钥缺失、上游失败或输出非法时，前端继续显示确定性解释。

## 5. Python 后端现状

已实现：

- FastAPI 应用工厂、配置、统一错误和请求 ID；
- 23 个运行中接口中的健康、上传、列表、详情和删除；
- SQLite 模型、Alembic 迁移和制品存储；

- 仿真时间基准、噪声、真值隔离和 fixture；

未实现/未部署：

- 单频/多频/AM/FM Python 估计器；
- 变量树、映射、质量和序列 API；
- 前端联调；
- 云端部署。

## 6. 架构约束

1. 浏览器 MVP 与 Python 后端不得形成两套无法同步的数值定义。
2. 任何 LLM 输出都不能修改数值结果。
3. Qoder Sites 只能托管静态文件和单个 Deno Function。
4. 数据持久化、SQLite 和任意 Python 进程不在当前线上架构内。
5. 后续若恢复完整后端，应明确选择“Sites 前端 + 外部 Python API”或“全量迁移到 Sites 可行技术栈”，不能含糊宣称已部署。
