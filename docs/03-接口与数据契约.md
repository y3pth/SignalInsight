# 接口与数据契约

## 1. 接口版本

| 接口 | 版本/路径 | 说明 |
|---|---|---|
| Python HTTP API | `/api/v1`, OpenAPI 1.1.0 | 完整目标契约 |

## 2. Python API 已实现接口

当前运行时已实现：

| 方法 | 路径 | 状态码 |
|---|---|---|
| GET | `/api/v1/health` | 200 |
| POST | `/api/v1/datasets` | 201 |
| GET | `/api/v1/datasets` | 200 |
| GET | `/api/v1/datasets/{dataset_id}` | 200/404 |
| DELETE | `/api/v1/datasets/{dataset_id}` | 204/404/409 |

OpenAPI 还声明了其余分析、批量、解释、仿真和导出接口，但它们尚未注册到运行时，不能视为已可用。

## 3. 统一错误

```json
{
  "error": {
    "code": "DATASET_NOT_FOUND",
    "message": "Dataset not found.",
    "details": {},
    "request_id": "uuid"
  }

```

关键错误码：

- `VALIDATION_ERROR`
- `UNSUPPORTED_FILE_FORMAT`
- `EMPTY_FILE`
- `FILE_TOO_LARGE`
- `DATASET_NOT_FOUND`
- `DATASET_IN_USE`
- `INTERNAL_SERVER_ERROR`

## 4. 数据格式与边界

| 项目 | 后端契约 | 线上 MVP |
|---|---|---|
| 文件 | CSV/MAT | CSV |
| 通道 | 1–32 | 1 |
| 采样 | 均匀/非均匀 | 近似均匀 |
| 数据类型 | 实/复解析/复基带 | 实数 |
| 文件大小 | 50 MiB | 浏览器限制 10 MiB |
| 样本数 | 64–500,000 | 64–500,000 |
| 总数值数 | ≤2,000,000 | 由浏览器限制 |
| 显示点数 | ≤5,000 | 局部窗口 |
| 单位 | s、Hz、rad、a.u. | s、Hz、rad、a.u. |

CSV MVP 规则：

- UTF-8/BOM；
- 逗号、制表符、分号；
- 必须有唯一表头；
- 时间和信号列由用户确认；
- 缺失、NaN、Infinity 不允许；
- 不做插值或静默修正。

## 5. 浏览器分析结果

前端分析结果包含：

```text
sampleCount
sampleRate
duration
nyquist
spectrum
candidates[]
best
unknown
recommendedId
reliability { level, evidence, limitations, nextSteps, bicGap }
series { time, observed, fitted, residual }
```

每个候选包含：

- 模型 ID / 标签；
- 频率分量数；
- 参数：offset、frequency、amplitude、phase；
- RSS、RMSE、R²、AIC、BIC；
- 残差 RMS、ACF、残余主频和显著度。

## 6. AI Function 契约

请求：

```json
{
  "unknown": false,
  "recommendedModel": "单频模型",
  "sampleCount": 2048,
  "sampleRate": 1024,
  "duration": 2,
  "candidates": [],
  "reliability": {
    "level": "reliable",
    "evidence": [],
    "limitations": []
  }
}
```

成功响应：

```json
{
  "ok": true,
  "explanation": {
    "summary": "string",
    "observations": ["string"],
    "limitations": ["string"]
  },
  "provider": "dashscope-compatible",
  "model": "qwen-plus"
}
```

限制：

- POST only；
- 64 KiB 请求上限；
- 最多 6 个候选；
- 25 秒上游超时；
- 不返回密钥、上游异常细节或原始响应。

## 7. 契约生成

```bash
cd backend
uv run python -m app.contracts.generate
uv run python -m app.contracts.examples
python -c "import json; from pathlib import Path; from openapi_spec_validator import validate; s=json.loads(Path('../contracts/openapi.json').read_text(encoding='utf-8')); validate(s)"
```

生成文件：

- `contracts/openapi.json`
- `contracts/examples/backend/*.json`
- `contracts/compatibility.md`
