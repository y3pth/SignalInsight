## 核心函数

- `generate_timebase()`：生成均匀或严格递增的非均匀时间序列及保留索引。
- `measure_signal_power()`：按 `mean(abs(x)^2)` 计算样本功率。
- `snr_db_to_linear()`：转换 SNR dB 并拒绝数值溢出。
- `apply_gaussian_noise()`：生成实数或圆对称复数高斯噪声并报告实际 SNR。
- `generate_simulation()`：组合模型生成器、时间、噪声、分析输入和独立真值。
- `compute_signal_sha256()`：对规范化数组和时间计算源哈希。
- `canonical_json_sha256()`：计算规范 JSON 哈希。
- `compute_file_sha256()`：分块计算文件哈希。
- `write_simulation_fixture()`：原子写入 analysis、truth 和 manifest。
- `read_analysis_fixture()`：只读取无真值的分析输入。
- `read_simulation_truth()`：显式读取隔离的模型真值。
- `validate_simulation_fixture()`：校验路径、文件哈希、源哈希、clean+noise 和 SNR 可重算性。
- `SimulationSampling.validate_sampling()`：校验非均匀采样必须真实存在抖动或丢样。

## 接口标准核对

- HTTP 接口：本任务不新增运行时接口；`POST /api/v1/simulated-datasets` 仍是契约占位，未宣称可用。
- 配置契约：复用 SimulationRequest/SimulationSampling，保持模型、信号类型、采样、噪声、SNR、随机种子和单位字段。
- SNR 定义：明确为 `10*log10(mean(abs(clean)^2)/mean(abs(noise)^2))`；复数按总复功率计算。
- 真值隔离：分析输入不含 model_id、真实参数、随机种子、clean_values 或 noise_values。
- 可复现：相同配置和随机种子生成相同数组及 SHA-256。
- 文件安全：NPZ 读写禁止 pickle；fixture 路径必须位于根目录内；写入采用临时文件替换且不覆盖非空目录。
- 内容一致性：验证分析信号=clean+noise、目标/实际 SNR、采样率、信号类型和时间递增。
- 偏差：无已知接口偏差；FE 评审和真实仿真 API 实现仍属于后续工作。
