## 核心函数

- `parse_csv()`：CSV 主解析入口，返回 descriptors、候选和验证摘要。
- `_detect_delimiter()`：CSV 分隔符检测。
- `_infer_column()`：逐列数值/缺失/非有限值分类。
- `_strictly_increasing()`：时间列候选判定。
- `_mapping_candidates()`：实时域和 I/Q 映射候选。
- `CsvParseError`：稳定错误码和细节。

## 接口标准核对

- HTTP 接口：不新增运行时接口，解析器供后续 Dataset 变量/映射 API 使用。
- Schema：直接返回 Dataset 契约中的 VariableDescriptor、MappingCandidate、ValidationSummary。
- 单位：CSV 默认幅值 `a.u.`，时间单位由后续映射确认，不在此处猜测。
- 错误：EMPTY_FILE、INVALID_ENCODING、DELIMITER_NOT_DETECTED、EMPTY_HEADER、DUPLICATE_HEADER、ROW_LENGTH_MISMATCH、CELL_LIMIT_EXCEEDED、NO_DATA_ROWS。
- 偏差：CSV 变量 API 尚未注册，属于 SI-P1-05；时间/采样率最终由用户确认。
